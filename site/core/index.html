Installing

From the first tagged release onward:

go install cruthu.dev/core/cmd/cruthu@latest

The module path is served from this domain rather than from the code host, so imports stay stable if the repository ever moves. There is no /v1 suffix: Go's semantic import versioning omits the suffix for v0 and v1, and a /v2 would be added only at a breaking major version.

Nothing importable lives outside internal/ yet, so this path resolves as an install target rather than as a library. Public packages arrive when the output schemas stabilize. Until then, see the status note in the README.
